# 「星际护航」小游戏 PRD（项目案例）

> 这是一份**项目案例 PRD**：一款竖屏打飞机休闲小游戏，含标准 **9 人团队**的人员架构、组织汇报线、任务与依赖关系。
> 可直接作为 doc-parse 板块的演示输入，让 DeepSeek 抽出「9 人组织 + 任务 + 依赖 + 推荐分工」。

---

## 1. 项目概述

- **一句话**：「星际护航」是一款轻量级竖屏打飞机休闲小游戏，玩家操控飞船击退 AI 入侵者、守护母舰。
- **产品形态**：H5 小游戏，单机可玩，含排行榜与每日关卡。
- **目标**：3 个月内上线，验证「轻休闲 + 强反馈」玩法。
