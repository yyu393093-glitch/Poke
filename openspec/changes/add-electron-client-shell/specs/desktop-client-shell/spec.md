## Purpose

为 Poke 提供可验证的桌面客户端生命周期，使现有 React 应用能够在单实例 Electron 容器中安全运行，并具备托盘、快捷键、窗口恢复和明确退出语义。

## ADDED Requirements

### Requirement: 客户端保持单实例
客户端 MUST 保证同一用户会话中只运行一个 Poke 主进程，并复用既有主窗口与悬浮窗口。

#### Scenario: 重复启动客户端
- **WHEN** 用户在客户端已经运行时再次启动 Poke
- **THEN** 第二个进程退出并聚焦已有主窗口
- **AND** 系统不创建第二个悬浮助手实例

### Requirement: 客户端提供三种悬浮助手入口
客户端 SHALL 支持全局快捷键、系统托盘和主程序按钮唤起悬浮助手。

#### Scenario: 首次通过快捷键唤起
- **WHEN** 悬浮助手尚未创建且用户按下 `Alt+A`
- **THEN** 客户端创建并显示悬浮助手
- **AND** 输入区域获得焦点

#### Scenario: 快捷键冲突
- **WHEN** 默认全局快捷键注册失败
- **THEN** 主程序和托盘入口仍然可用
- **AND** 客户端向用户展示可理解的冲突提示

### Requirement: 关闭和退出具有不同语义
客户端 MUST 将窗口关闭操作解释为隐藏，将托盘“完全退出”解释为销毁全部窗口并结束后台进程。

#### Scenario: 用户关闭悬浮窗口
- **WHEN** 用户点击悬浮窗口的关闭按钮
- **THEN** 悬浮窗口隐藏但客户端后台进程继续运行
- **AND** 当前会话状态不丢失

#### Scenario: 用户从托盘完全退出
- **WHEN** 用户选择托盘菜单中的“完全退出客户端”
- **THEN** 客户端注销全局快捷键、销毁全部窗口并结束进程

### Requirement: 客户端恢复安全窗口配置
客户端 SHALL 保存并恢复悬浮窗口的位置、尺寸、置顶状态、快捷键和浮球状态，同时保证恢复后的窗口位于可见屏幕范围。

#### Scenario: 重启恢复配置
- **WHEN** 用户调整窗口后正常退出并重新启动客户端
- **THEN** 客户端恢复上次有效的位置、尺寸和置顶状态

#### Scenario: 配置损坏或窗口位于屏幕外
- **WHEN** 本地配置无法解析或保存坐标不在当前显示器可见区域
- **THEN** 客户端使用安全默认配置并将窗口放回可见区域

### Requirement: Renderer 与 Node 权限隔离
客户端 MUST 禁止 Renderer 直接访问 Node、Electron、文件系统、命令执行或任意 IPC 通道，只允许使用白名单 Bridge 能力。

#### Scenario: Renderer 请求未授权能力
- **WHEN** Renderer 尝试调用未在白名单声明的通道或传递未知字段
- **THEN** 客户端拒绝请求且不执行任何系统操作
